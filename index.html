Privacy policy

for vibe coders

If you already vibe code with Bolt.new, Lovable, v0 or Replit Agent on desktop, this is the same flow on your phone — with your actual Cursor account underneath.

VibeCursor Bolt.new Lovable v0 Replit Agent Windsurf Claude Code

Independent unofficial Android client. Not affiliated with Cursor, Anysphere, or the tools named above — listed only so you know what to expect.

what you get

Multi-account Cursor

Switch accounts on one phone without the login shuffle.

Multi-chat

Several chats per project — pin, switch, delete without losing the others.

App lock

Optional password at launch — lock in the ☰ menu opens Settings.

App language

Automatic (follows the phone), EN / IT and more — in Settings.

Linux system backup

Save your personal root (installed tools), restore it, or factory-reset if Linux breaks. Your projects stay.

Persistent memory

Facts and project context that survive new chats.

Lite ↔ CLI

Light chat or terminal-style feed — one tap in the header.

Plan / Ask / Run

Draft a plan, ask, or let it run end-to-end.

Checkpoint

Snapshot the project and restore when something goes sideways.

Preview tabs

Multiple preview ports; closing preview keeps your tabs for next open.

Preview & publish

Live preview on device — on tablet: chat left, site right. One-tap public URL.

Git + MCP

Commit and push on phone; connect MCP servers.

OTA updates

UI updates itself — no APK hunt for every tweak.
