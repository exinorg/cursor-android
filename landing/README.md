# VibeCursor landing (Phone + Tablet carousel)

Static page for https://vibecursor.euroapp.site

The **Phone / Tablet** demo stage is HTML + CSS + a small JS carousel in `index.html`
(not screenshot images). Toggle Phone ↔ Tablet; scenes rotate every few seconds.

Deploy: sync this folder to the VPS web root (see `vibecursor.euroapp.site.nginx`).
